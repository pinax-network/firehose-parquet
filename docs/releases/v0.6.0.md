# firehose-parquet v0.6.0

## Breaking changes

- `fireparq build` is now the only ingestion entrypoint; invoking ingestion flags directly at the root command is no longer supported.
- Deprecated CLI aliases have been removed:
  - `partitions build --partition-types`
  - `rollup --target-partition`
  - `scan --rows`
- `partitions.parquet` readers now accept only the canonical layout:
  - required columns: `partition`, `start_block`, `stop_block`
  - required metadata: `firehose-parquet.partition`
  - optional current-format `chain` column or `firehose-parquet.chain_name` metadata

## Upgrade notes

- Update automation and shell snippets to call `fireparq build ...`.
- Rewrite any legacy partition indexes that still use `partition_type`, `partition_value`, `end_block`, or old compatibility metadata before using the current CLI readers.
